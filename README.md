# 音频分析 Audio Analysis

面向 AI 音频、AI 音乐与音视频评测标注的 macOS 桌面工具。离线批量测量响度、峰值、频谱、疑似满幅削波和 BPM，支持曲库、试听、图表以及 CSV / JSON 导出。

## 下载与安装

在 [GitHub Releases](https://github.com/zyding123/audio-analysis-app/releases/latest) 下载 **v1.1.0 Apple Silicon DMG**，打开后将“音频分析”拖入 Applications。应用仅做本地处理，不上传音频。安装包为临时签名，尚未使用 Apple 开发者证书公证；系统首次打开时可能需要在“系统设置 → 隐私与安全性”中允许。

## v1.1.0 更新

- 分别计算各声道的频谱与节拍证据，避免直接相加/相减丢掉反相素材或中置声部。
- 满幅平台检查结合连续性、极性与平坦程度，修复低频干净正弦的误报；结果明确标为“疑似”，不把检测结果当作可听失真的证明。
- 失败和不可用指标显示“—”，CSV 用空值、JSON 用 `null`；保留错误和可靠性提示。
- 修复清空、停止、替换批次的状态恢复；GUI 更新始终在主线程，所有退出路径先结束后台线程。
- 文件版本使用纳秒修改时间与大小记录；检测到文件更新后要求重新分析，防止旧指标配新图表。
- 修复生成图表期间覆盖文件的缓存问题、重新打开窗口后被误清理的问题，以及并发绘图竞争。
- 解码采用自动清理的临时文件映射；削波与频谱逐块计算，长音频图表限制显示帧数，降低峰值内存占用。停止可终止 FFmpeg 子进程。
- 版本号统一由 `version.py` 提供；发布前自动回归检查、验证签名并运行打包后自检。

## 使用

1. 将音频/视频或文件夹拖入右侧区域，或使用“打开文件”。左侧曲库用于暂存文件，双击开始分析。
2. 选择一行后播放/暂停，空格键切换；拖动底部进度条定位。红线为疑似满幅平台位置。
3. 双击记录查看频谱热力图和平均功率谱，可保存 PNG。
4. 导出 CSV 或 JSON。失败指标为空，错误列和 `warnings` 说明原因。文件在分析后被覆盖或移除时，导出清空旧指标并标明源文件已变更。

## 指标定义与适用范围

| 指标 | 定义 |
| --- | --- |
| LUFS | FFmpeg `ebur128` 积分响度；纯静音或未得到有效测量块时为空 |
| LRA | FFmpeg `ebur128` 响度范围；短于 30 秒的内容附参考性提示 |
| True Peak | FFmpeg 过采样峰值，dBTP；超过 0 时提示采样点间越界风险 |
| Sample Peak | 解码后所有声道样本最大绝对值的 dBFS |
| 幅度加权频谱质心 | 每帧先对各声道幅度谱求和，再计算 `Σf·M / ΣM`，对有效帧平均 |
| 功率加权频谱质心 | 每帧先对各声道功率谱求和，再计算 `Σf·P / ΣP`，对有效帧平均 |
| 疑似满幅削波 | 同极性、接近满幅且平坦的连续样本平台，以及超过 ±1 的样本；不是听感失真判决 |
| BPM | 各声道 onset 强度汇总后的自动速度估计；弱节拍证据时为空 |

频谱质心默认帧长 2048、帧移 512；极短片段缩短帧长。空静音帧不参与质心平均。**v1.1 的多声道频谱口径与 v1.0 单声道降混口径不同**，跨版本比较时请重新分析全部样本。

热力图采用各声道平均功率，相对该文件峰值显示 -70~0 dB；它显示频率结构，不用于比较不同文件的绝对响度。纯静音显示最低色阶。长音频自动降低图表时间分辨率，检查很短的瞬态请使用较短片段。

自动 BPM 有半速、倍速或其他节奏歧义；只取中间最多 120 秒，不能描述整首变速过程。短音频 LRA、自由节拍/氛围声音的 BPM 均应人工复核。底层 BPM 库正在计算时，“停止”会在该调用返回后完成；FFmpeg 和逐块计算可在处理中取消。

临时 PCM 使用磁盘空间：1 小时 48 kHz 双声道约 1.38 GB，在分析结束后释放。文件版本检测依赖时间戳与大小，非内容哈希。v1.0 历史记录没有源文件版本信息，会保留并提示重新分析。

## 源码运行和验证

Python 3.13，使用独立虚拟环境：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-build.txt
python main.py
python -m unittest discover -s tests -v
QT_QPA_PLATFORM=offscreen python main.py --self-test
bash build_macos.sh
```

`static-ffmpeg` 在首次源码运行时可能下载 FFmpeg。发布的 App 已内置 FFmpeg / ffprobe，用户无需安装 Python 或运行环境。

构建输出位于 `dist/v1.1.0/`：App、DMG、SHA-256 校验文件。DMG 同时包含 Applications 快捷方式。GitHub Actions 在推送代码时检查测试和打包，主分支通过检查后按 `version.py` 创建对应的 Release 和标签；同版本已发布文件不会被覆盖。

## 项目文件

- `analyzer.py`：测量、取消、分块处理及数据模型
- `main.py`：Qt 界面、任务生命周期、曲库、试听和导出
- `charts.py`：多声道频谱与图表生成
- `version.py`：版本号与构建号
- `tests/`：自动回归检查
- `smoke_test.py`：独立数据目录下的源码/打包自检
- `build_macos.sh`：构建、签名验证、自检、生成安装包
